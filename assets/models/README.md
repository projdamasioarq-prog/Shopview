# Modelos 3D

Adicione aqui modelos `GLB` ou `GLTF` dos produtos. No arquivo `data/products.json`, informe o caminho em `model3d`, por exemplo:

```json
"model3d": "assets/models/fone-wireless.glb"
```

Prefira modelos otimizados para web e publique apenas arquivos que você tenha autorização para utilizar.
