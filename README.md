# ShopView Store

Loja de produtos afiliados com catálogo responsivo e visualização 3D de modelos GLB/GLTF.

## Publicação
1. Abra Settings → Pages.
2. Em Build and deployment, escolha Deploy from a branch.
3. Selecione `main` e `/ (root)` e salve.

## Produtos
Edite `data/products.json` para cadastrar produtos, imagens, modelos 3D e links de afiliado Shopee. O painel `admin.html` ajuda a editar o catálogo e exportar o JSON.

Os produtos de demonstração devem ser substituídos por ofertas reais e informações verificadas. O painel é local, sem autenticação ou banco de dados.
